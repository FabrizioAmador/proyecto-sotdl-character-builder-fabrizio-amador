El punto de este proyecto es que sea una página que te permita contruir hojas de personaje de Shadow of the Demon Lord (Sombra del Señor Demonio).

Los personajes empiezan con 4 estadísticas (puntos de Fuerza, Intelecto, Agilidad, Voluntad) que determinan sus "Características" (Vida Máxima, Insanidad, Percepción y Defensa)

Acá se podrá seleccionar para crear un personaje nivel 0:
Razas: Humano, Orco, Enano, Autómata o Goblin. Al seleccionar una raza el jugador tiene la posibilidad de sumar un punto a una estadística en pos de restarle un punto a otra. Esto sería el "carrito" que se acomplejará a medida que más detalles del personaje se seleccionen.

A medida que se sube de nivel la raza otorga poderes.
Sendas: Las llamadas "clases" de fantasía que determinan habilidades y/o hechizos y rol general en combate. Hay tres tipos de clase: Novicia, Experta y Maestra. Cada uno aporta modificación a las estadísticas del personaje (en general, se puede elegir en subir en 1 o 2 puntos a una estadística/s a elección). El sistema está pensado para que cada vez que se suba de nivel, adquieras mejoras para el personaje por o la raza o una de las sendas.

Subir de nivel ocurre a lo largo de una campaña, por lo que será necesario que la página de la opción de guardar el personaje.

Más adelante, la idea es que a aplicación pueda asistir en cuantos dados tengas que usar para realizar cierta acción (varias habilidades o situaciones suman o restan esos dados[NO la tirada, solo la cantidad])
